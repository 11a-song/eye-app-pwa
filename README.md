# 연세제일안과 모바일 PWA

HTML, CSS, JavaScript로 구성한 모바일 안내 앱입니다. 외부 패키지 설치나 빌드 없이 실행합니다.

## 로컬 실행

Node.js가 설치된 환경에서 `npm run dev`를 실행하고 http://localhost:4173 을 엽니다.
파일을 직접 열어도 기본 화면을 볼 수 있지만 서비스 워커 및 PWA 설치에는 HTTP(S)가 필요합니다.

## 구성

- 홈과 6개 메뉴 페이지: `#/guide`, `#/schedule`, `#/before`, `#/after`, `#/dream`, `#/faq`
- 내정보 화면: `#/profile` (개인 진료 정보 및 로그인 미연결)
- 공통 하단 메뉴: 홈, 내정보, 가운데 원형 문의 버튼, 언어선택
- 문의: 기존 홈페이지의 카카오톡 채널, 네이버 예약, 대표전화 연결
- 언어: 한국어·영어·중국어 기본 메뉴 및 탐색 UI. 병원 원문 안내는 한국어 유지
- PWA: manifest, PNG 아이콘, standalone 표시, 공개 정적 파일만 오프라인 저장
- 업데이트: 네트워크 우선으로 최신 파일을 조회하고 실패 시 저장된 파일 표시. 캐시 구조 변경 시 sw.js의 CACHE 버전 변경

## 참고 및 미연결 사항

기존 `C:\Users\2025w\OneDrive\Desktop\Git-song22\song-22`의 로고, 내부 사진, 진료시간, 의료진 이름, 상담 링크와 시력교정 안내 일부를 참고했습니다. 원본은 변경하지 않았습니다.

진료시간은 기존 정적 홈페이지에 기재된 정보이며 운영 전 병원 확인이 필요합니다. 원장별 진료 일정은 기존 홈페이지와 동일한 Supabase 공개 테이블(doctors, doctor_weekly_schedules, doctor_date_schedules, doctor_closures)을 조회합니다. 날짜별 일정은 주간 기본 일정보다 우선하고, 휴진 기간은 모든 진료 일정보다 우선합니다. 격주 토요일과 기존 공휴일 규칙도 유지합니다. 월 이동, 의료진 및 휴진 필터, 선택일 진료시간, 월별 휴진 안내를 제공합니다.

일정 데이터는 공개용 키로 읽기만 하며 브라우저에 영구 저장하지 않습니다. 메뉴 진입 시 최신 데이터를 확인하고, 1분 이내 재진입은 메모리의 조회 결과를 사용합니다. 조회 실패나 오프라인 상태에서는 가상의 일정이나 이전 일정을 표시하지 않고 재시도 안내를 제공합니다. 개인 정보는 아직 미연결입니다. 수술 후·드림렌즈 상세 의료 안내는 병원 확정 내용으로 교체할 수 있도록 구성했습니다.

일정 화면은 참고 홈페이지와 같이 원장별 색상 버튼, 종일/오전 구분 점, 주 단위 휴진 기간 띠, 의료진 사진이 있는 선택일 카드와 병원 진료시간을 제공합니다. 하단 진료시간은 관리자 페이지가 관리하는 `clinic_hours`에서 조회합니다. 해당 테이블을 읽을 수 없는 경우 기존 홈페이지 기본 진료시간을 유지합니다. 의료진 사진을 불러오지 못하면 기본 프로필 아이콘을 표시합니다.

`npm test`로 일정 규칙 검증, `node tests/schedule.cjs --live`로 실제 공개 조회와 기존 홈페이지의 일정 계산 결과 비교를 수행합니다.

## 모바일 설치

공개 운영에는 HTTPS 배포가 필요합니다. localhost는 개발용 예외입니다. 안드로이드 Chrome에서 앱 설치 또는 홈 화면에 추가, iOS Safari에서 공유 → 홈 화면에 추가를 사용합니다. 오프라인 상태에서도 한 번 방문한 앱 안내를 볼 수 있으며 외부 상담·예약에는 인터넷이 필요합니다.
