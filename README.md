# 연세제일안과 모바일 PWA

HTML, CSS, JavaScript로 구성한 모바일 안내 앱입니다. 외부 패키지 설치나 빌드 없이 실행합니다.

## 로컬 실행

Node.js가 설치된 환경에서 `npm run dev`를 실행하고 http://localhost:4173 을 엽니다.
파일을 직접 열어도 기본 화면을 볼 수 있지만 서비스 워커 및 PWA 설치에는 HTTP(S)가 필요합니다.

## 구성

- 관리자: `admin.html` · [연결 및 설정 안내](ADMIN_SETUP.md)

- 홈과 6개 메뉴 페이지: `#/guide`, `#/schedule`, `#/before`, `#/after`, `#/dream`, `#/faq`
- 내정보 화면: `#/profile` (개인 진료 정보 및 로그인 미연결)
- 공통 하단 메뉴: 왼쪽 홈, 가운데 원형 문의 버튼, 오른쪽 내정보
- 문의: 기존 홈페이지의 카카오톡 채널, 네이버 예약, 대표전화 연결
- 병원 이용 안내: 보훈·지원 → 시설 → 의료진 → 장비 → 연혁 탭으로 한 항목씩 표시합니다. 시설 사진은 좌우 넘김, 의료진·장비는 펼쳐 보기로 구성했습니다. 보훈 상세는 앱 내부 창에서 대상별 지원 카드와 공통 조건을 보여주며 상단·하단 닫기 버튼을 제공합니다. 보훈 지정 시점은 병원 확인에 따라 2026년 1월로 반영했습니다.
- 의료진·장비·진료시간·내원 안내는 새 Supabase의 공개 데이터를 사용합니다. 보훈 원문·시설 사진·연혁은 요청한 홈페이지의 2026-11-12 자료를 앱 파일에 반영했습니다(`scripts/guide-reference.js`, `assets/facility/`). 참고 홈페이지는 변경하지 않았습니다.
- 언어: 로고 옆 `KR | EN | CN` 버튼으로 한국어·영어·중국어 기본 메뉴 및 탐색 UI 전환. 병원 원문 안내는 한국어 유지
- PWA: manifest, PNG 아이콘, standalone 표시, 공개 정적 파일만 오프라인 저장
- 업데이트: 네트워크 우선으로 최신 파일을 조회하고 실패 시 저장된 파일 표시. 캐시 구조 변경 시 sw.js의 CACHE 버전 변경

## 참고 및 미연결 사항

기존 `C:\Users\2025w\OneDrive\Desktop\Git-song22\song-22`의 로고, 내부 사진, 진료시간, 의료진 이름, 상담 링크와 시력교정 안내 일부를 참고했습니다. 원본은 변경하지 않았습니다.

진료시간은 참고 홈페이지 정보이며 운영 전 병원 확인이 필요합니다. 공개 콘텐츠와 이미지를 PWA 전용 Supabase `issyhftzmzpudoeidoum` 및 앱 파일로 이전했고 앱과 관리자 모두 새 프로젝트를 사용합니다. 기존 홈페이지 수정은 자동 동기화되지 않습니다. 관리자 계정 생성 절차와 이전·검증 결과는 [ADMIN_SETUP.md](ADMIN_SETUP.md)에 있습니다. 원장별 진료 일정은 새 프로젝트의 공개 테이블(doctors, doctor_weekly_schedules, doctor_date_schedules, doctor_closures)을 조회합니다. 날짜별 일정은 주간 기본 일정보다 우선하고 휴진 기간은 모든 진료 일정보다 우선합니다. 격주 토요일, 공휴일 규칙, 월 이동, 의료진·휴진 필터와 선택일 진료시간을 제공합니다.

일정 데이터는 공개용 키로 읽기만 하며 브라우저에 영구 저장하지 않습니다. 메뉴 진입 시 최신 데이터를 확인하고, 1분 이내 재진입은 메모리의 조회 결과를 사용합니다. 조회 실패나 오프라인 상태에서는 가상의 일정이나 이전 일정을 표시하지 않고 재시도 안내를 제공합니다. 개인 정보는 아직 미연결입니다. 수술 후·드림렌즈 상세 의료 안내는 병원 확정 내용으로 교체할 수 있도록 구성했습니다.

일정 화면은 참고 홈페이지와 같이 원장별 색상 버튼, 종일/오전 구분 점, 주 단위 휴진 기간 띠, 의료진 사진이 있는 선택일 카드와 병원 진료시간을 제공합니다. 하단 진료시간은 관리자 페이지가 관리하는 `clinic_hours`에서 조회합니다. 해당 테이블을 읽을 수 없는 경우 기존 홈페이지 기본 진료시간을 유지합니다. 의료진 사진을 불러오지 못하면 기본 프로필 아이콘을 표시합니다.

`npm test`로 일정 규칙 검증, `node tests/schedule.cjs --live`로 실제 공개 조회와 기존 홈페이지의 일정 계산 결과 비교를 수행합니다.

## 모바일 설치

공개 운영에는 HTTPS 배포가 필요합니다. localhost는 개발용 예외입니다. 안드로이드 Chrome에서 앱 설치 또는 홈 화면에 추가, iOS Safari에서 공유 → 홈 화면에 추가를 사용합니다. 오프라인 상태에서도 한 번 방문한 앱 안내를 볼 수 있으며 외부 상담·예약에는 인터넷이 필요합니다.

배포 주소: https://jeileye.2025work11a.workers.dev/
홈 화면의 ‘앱 설치’ 버튼은 지원 브라우저의 설치 창을 열고, 아이폰 및 인앱 브라우저에서는 기기별 설치 방법을 안내합니다. 설치된 앱으로 실행하면 설치 버튼이 숨겨집니다. 설치 창을 취소한 경우 브라우저 메뉴에서도 설치할 수 있습니다.

모바일 첫 접속에는 설치 안내 화면을 먼저 표시합니다. 앱의 standalone 실행과 지원 브라우저의 getInstalledRelatedApps 조회로 설치 상태를 확인하며, 지원하지 않는 브라우저에서는 기기 전체의 설치 여부를 확정할 수 없습니다. ‘브라우저로 계속 이용하기’는 현재 방문 동안 안내를 닫습니다. 인앱 브라우저·삼성 인터넷에서는 설치 버튼으로 Chrome 전환을 시도하고, Chrome에서는 사용자 클릭으로 설치 확인창을 엽니다. 외부 브라우저 전환 이후에는 새 페이지에서 다시 설치 버튼을 눌러야 할 수 있으며, iOS는 Safari의 홈 화면에 추가를 사용합니다. 강제 설치나 보안 경고 우회는 하지 않습니다.

이미지 성능(2026-11-13): 시설·가져온 공개 이미지·안약 사진 41개를 비율 유지한 모바일 해상도로 최적화했습니다(합계 약 9.11MB → 3.05MB). 원본은 Git 이전 버전과 로컬 .tmp/image-originals에 보관합니다. 큰 사진을 초기 SHELL 선다운로드에서 제외하고, 같은 출처 assets/의 공개 이미지에만 기기 캐시 우선 정책을 적용합니다. 사진 변경 배포 시 sw.js CACHE 버전을 반드시 갱신합니다. API·관리자 응답·다른 출처 이미지는 이 캐시 대상이 아닙니다.

첫 실행 성능(2026-11-13): index.html은 홈 메뉴와 설치 첫 화면을 HTML로 먼저 표시합니다. CSS 9개와 스크립트 13개는 assets/app.css 및 assets/app.js로 묶었으며 원본 수정 후 npm run build가 필요합니다. npm run check가 생성 파일의 일치 여부를 검사합니다. 프리텐다드는 공식 v1.3.9 가변 분할 폰트 92개를 로컬에 보관하고 실제 화면의 글자에 필요한 파일만 요청합니다(홈/설치 안내 기본 문구 기준 약 38KB). 기존 전체 폰트의 preload와 선다운로드를 제거했습니다. 공개 앱 파일도 CACHE 버전 단위의 캐시 우선 정책으로 전환했으므로, 배포 시 빌드를 갱신하고 sw.js CACHE를 올려야 합니다. 새 서비스 워커는 열려 있는 이전 앱 창이 모두 닫히면 활성화됩니다. API와 관리자 페이지는 계속 캐시에서 제외합니다.

홈 복귀 동작: 홈 버튼/상단 로고 및 홈으로 돌아오는 해시 이동 시 병원 안내 탭, 달력의 월·날짜·원장 필터, 미완료 화면 입력, 열린 알림창과 스크롤을 초기화합니다. 홈 링크는 현재 앱 경로를 #/로 교체하고 화면을 새로 구성합니다. 이전 진료 일정 요청의 늦은 응답은 세대 번호로 무시합니다. 수술 일정·약 체크 기록·언어 설정과 정적 파일 캐시는 삭제하지 않습니다.
